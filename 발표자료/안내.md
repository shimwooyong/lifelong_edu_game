# 발표 자료

- **배움의일생_게임규칙.pptx**: 게임 규칙 소개 발표 (8장, 5~7분, 슬라이드마다 발표 대본이 '슬라이드 노트'에 들어 있음)

- **QR_게임접속.png**: 학생 접속 주소(https://shimwooyong.github.io/lifelong_edu_game/) QR코드 이미지. 마지막 슬라이드에도 들어 있음. `qr.js`는 외부 도구 없이 QR을 만드는 코드.

- **진행자_큐시트.docx**: 진행자 2명용 순서표(수업 전 준비·진행 순서·뉴스 5개·토론 질문·돌발 상황). Word로 바로 고칠 수 있음. `큐시트_만들기.ps1`로 다시 만들 수 있음.

- **진행자_힌트시트.docx**: 모든 이벤트(뉴스 세상 이벤트 포함 41개)의 선택지와 결과(자산 변화·좋은 교육 여부·확률·★Help 최고 선택)를 A4 양면 2쪽에 정리. Word로 고칠 수 있음. 게임 데이터를 바꾸면 `힌트시트_만들기.ps1`로 다시 만듦(데이터는 미리보기에서 .claude/tmp/hint.json으로 뽑음).
- 받기: https://shimwooyong.github.io/lifelong_edu_game/발표자료/진행자_힌트시트.docx

## 다시 만들기
`만들기.ps1`을 PowerShell에서 실행하면 PowerPoint로 처음부터 다시 만듭니다(PowerPoint가 설치된 PC 필요).
그림은 `그림` 폴더(게임의 도트 그림을 크게 뽑은 것)를 씁니다.
